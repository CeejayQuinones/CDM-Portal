# CDM Portal

Campus Management System for Colegio de Montalban.

## Features

- Authentication
- RBAC
- Admission
- Enrollment
- Grading
- Student Management
- Registrar Appointment
- Document Requests
- CDM Buddy verified portal updates

## Tech Stack

- Laravel
- Vue 3
- Vite
- MySQL
- Capacitor
- Electron
